# 난임 시술 임신 성공 여부 예측 AI | 의료 데이터 머신러닝

> **6조 육캔두잇 · AI Healthcare Mini Project · 2026.10**
>
> IVF/DI 시술 기록과 임상적 맥락을 바탕으로 전처리·피처 엔지니어링·앙상블을 설계한 **교육용 팀 프로젝트**입니다. 본 프로젝트는 진단이나 개인별 시술 권고를 위한 임상 검증 도구가 아닙니다.

## 1. 문제 정의

환자 및 시술 관련 정보를 사용해 **해당 시술의 임신 성공 여부를 예측하는 확률 점수**를 계산합니다. ROC-AUC는 성공 사례를 실패 사례보다 더 높게 순위화하는 능력을 측정하며, **임신 성공 확률 74% 또는 예측 정확도 74%를 의미하지 않습니다.**

## 2. 임상 지식이 중요했던 지점

### 결측치의 구조적 의미

- **DI(인공수정) 6,291건**에서 배아 관련 여러 항목이 함께 결측인 것은 그 시술에서 해당 정보가 생성되지 않은 **구조적 결측**으로 해석했습니다.
- PGS·PGD 관련 항목의 많은 결측은 '검사 미시행' 가능성과 구분해 처리할 필요가 있습니다.
- 트리 계열 모델에서는 수치 결측을 임의로 0으로 대체하기보다 NaN을 보존하는 접근을 선택했습니다.

### 임상적으로 이해할 수 있는 파생변수

- **난자 나이 관련 변수**: 환자 나이만이 아니라 난자 기증 여부와 기증자 연령대를 고려
- **이식 여부**: 이식되지 않은 시술 단계와 실제 이식한 경우를 구별
- **이식 단계·배양일**: 배반포 이식 등 시술 단계 맥락을 반영
- **배아 활용 비율**: 생성·이식·저장 배아 수 사이의 관계를 비율로 설계
- **시술 이력**: 시술·임신·출산 횟수 문자열을 크기 순서를 보존하는 숫자로 변환

> 변수는 예측용 연관 정보이며, **특정 시술 방식을 선택하면 성공률이 올라간다는 인과 결론**은 낼 수 없습니다.

## 3. 모델과 실험의 발전 과정

| 단계 | 발표에서 제시한 결과 | 평가 의미 |
|---|---:|---|
| 2026.10.15 개발 중간안 | **OOF 약 0.7407 / 공개 LB 약 0.7422** | LightGBM·XGBoost·CatBoost 3종 기반 모델 |
| 최종 [A] 피처 수정 + 다중 분할 | **OOF 0.741126** | 65개·54개 등 피처 세트/모델 혼합 |
| [A]+[B] 팀원 별도 가공 모델 | **OOF 0.741170** | 별도 피처 가공·예측값 혼합 |
| 최종 [A]+[B]+[C] MLP | **OOF 0.741226 / 공개 LB 0.7424306** | 최종 팀 결과, 두 단계 블렌딩 |

최종 모델은 **[A] 피처수정 트리모델, [B] 별도 가공 트리모델, [C] MLP**를 결합한 팀 결과입니다. 제공된 `육캔두잇_3-3.ipynb`는 그보다 앞선 **3종 트리모델(LightGBM·XGBoost·CatBoost) 별도 코드**로, 최종 블렌딩과 동일하지 않습니다.

## 4. 피처 정의서와 코드의 관계

- 2026.10.15 피처정의서는 **원본 입력 67개 → 전처리 후 92개 피처** 구성을 다룹니다.
- 2026.10.20 최종 발표의 [A] 경로는 **후보 94개 → Null importance 기반 54개(S54)**를 별도로 선택했습니다.
- **92개와 54개는 서로 다른 단계/모델 경로의 수치**이므로 같은 최종 피처 개수로 혼용하지 않았습니다.

## 6. 핵심 교훈 및 제한

1. 임상적으로 이해 가능한 **구조적 결측**과 단순 오류를 구분할 수 있어야 함
2. 피처가 많아지는 것보다 **적절한 검증과 데이터 누수 예방**이 중요함
3. **OOF, 공개 리더보드, 외부 임상 검증**은 모두 다른 평가 단계임
4. 동일 환자 반복 시술, 의료기관 차이, 확률 보정(calibration), 실제 예측 시점에 사용 가능한 변수의 범위는 후속 검증이 필요함
