# 난임 시술 임신 성공 예측 모델

> 난임 시술 기록을 보고, 그 시술로 임신에 성공할 확률을 맞히는 모델

| 항목 | 내용 |
|---|---|
| 기간 | 2026.10 |
| 형태 | 미니 프로젝트 4명 (6조 '육캔두잇'), 대회형 과제 |
| 내 역할 | 데이터 탐색(EDA)·전처리, 빈칸(결측치)의 임상적 의미 해석, 모델 하나 담당, 발표 Part 1 |
| 사용 도구 | Python, pandas, scikit-learn, LightGBM, XGBoost, CatBoost |

## 1. 문제

시술 한 건의 정보로 임신 성공(1) / 실패(0)를 예측합니다.

| 항목 | 값 |
|---|---|
| 학습 데이터 | 256,351건 |
| 테스트 데이터 | 90,067건 |
| 입력 정보 | 67개 |
| 성공 비율 | 25.8% (네 명 중 한 명꼴) |
| 평가 점수 | ROC-AUC |

**ROC-AUC 쉽게 말하면**: 성공한 환자 1명과 실패한 환자 1명을 놓고, 모델이 성공한 사람에게 더 높은 확률을 주는지 보는 점수예요. 0.5는 아무렇게나 찍은 수준, 1은 완벽입니다.

## 2. 내가 찾은 것

- **빈칸에도 뜻이 있다**: 인공수정은 원래 배아 정보가 없고, 검사를 안 하면 검사 칸이 비어 있습니다. 그래서 빈칸을 평균으로 채우지 않고 "해당 없음"이라는 정보로 그대로 썼습니다.
- **환자 나이보다 난자 나이**: 기증 난자를 쓰는 경우가 있어서, 실제 난자의 나이가 더 중요한 정보였습니다.
- **임상 맥락을 담은 변수 설계**: 후보 변수 94개 중 최종 54개를 골랐고, 이식 단계 조합·난자 나이 등 파생변수 18개를 새로 만들었습니다.

## 3. 결과

- LightGBM·XGBoost·CatBoost 세 모델을 섞어서 **공개 리더보드 ROC-AUC 0.7424306** 달성
- 성공 환자와 실패 환자를 비교했을 때, 열에 일곱 번 이상 성공 환자를 더 높게 봤다는 뜻입니다.

## 4. 배운 점

- 처음 코드가 테스트 데이터까지 같이 보고 변환하고 있었습니다. 이건 **규칙 위반(데이터 누수)**이라 학습 데이터만 쓰도록 고쳐서 다시 제출했습니다. 점수보다 규칙을 지키는 게 먼저라는 걸 배웠습니다.
- 숫자만 보는 것보다, 임상 지식으로 "왜 비어 있는지"를 해석하는 게 성능에 도움이 됐습니다.
