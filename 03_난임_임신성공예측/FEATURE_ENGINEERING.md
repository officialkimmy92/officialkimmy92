# 난임 시술 예측 | 피처 엔지니어링과 임상적 해석

> 출처: `10.15_난임_피처정의서 (1).xlsx` (개요·피처정의서·전처리_최종피처·코드값정의 4개 시트) 및 팀 발표. 공개본은 **데이터 자체가 아닌 정의·전처리 방법의 요약**입니다.

## 분석 문제와 데이터
- 타깃: `임신 성공 여부` (0/1)
- 대회 학습 자료: **256,351행**, 테스트: **90,067행**; 성공 66,228건(25.8%)
- 원본 입력 변수: **67개**; 제출 식별자 `ID`는 예측 피처로 사용하지 않음
- 피처정의서 '개요'에는 일부 제외/검토 항목을, '전처리_최종피처'에는 92개 구성으로 가는 핵심 변환 규칙을 기록

## 1. 구조적 결측 (Not applicable vs. zero)

| 파생변수 종류 | 변수/처리 원칙 | 해석상 주의 |

| 배아 활용 | 이식 수/생성 수, 저장 수/생성 수 | 분모 0 또는 결측이면 NaN 유지 |

## 3. 두 개의 피처 실험 경로

### 중간 발표(10월 15일) — 92개

- 원본 67개 변수의 임상적 의미 검토와 문자열·범주·비율·결측 처리
- 2026.10.15 피처정의서의 `전처리_최종피처`에 **92개 피처 구성**이라고 명시
- LightGBM·XGBoost·CatBoost 기반 GBDT 모델 검토

### 최종 발표(10월 20일) — [A] 경로 S54

- 후보 피처 **94개**에서 **Null importance**를 이용해 **54개**를 선택
- 최종 54개 중 **18개 파생 피처** 포함
- `이식단계조합`, `이식_없음`, `난자나이_eff` 등이 중요한 변수로 제시
- [B] 경로는 별도로 가공한 92개 피처 사용; **[A] S54와 동일한 열 집합 아님**

## 4. QA 체크포인트 — 프로젝트 검토에서 도출
- 전처리 범주 사전·희귀범주 결정은 **train 또는 학습 Fold**에서만 학습하는 것이 원칙
- 학습 데이터와 테스트 데이터는 결합하여 범주 목록을 학습하지 않도록 검증 필요
- 데이터에 없는 환자정보·성공률을 추정해 채워 넣지 않음
- 시술 후에만 확인 가능한 변수로 **시술 전 상담 모델**의 성능을 평가하는 경우 정보시점 누수 가능성 점검
- 같은 환자의 반복 시술 기록이 섞인 경우 무작위 Fold로 환자 단위 정보가 새어 나갈 가능성 검토

이 항목들은 **후속 QA 체크포인트**이며, 모든 검증을 실제 완료했다는 뜻은 아닙니다.
