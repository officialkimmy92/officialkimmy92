# 난임 임신 성공 예측 — 팀 발표 핵심 자료
**출처:** 2026-10-20, 6조 AI Healthcare Mini Project 발표자료 (13장) 핵심 내용의 텍스트 정리

## 문제 정의
시술/환자 변수로 임신 성공 여부를 예측하는 **교육용 이진 분류 모델**. 의료적 의사결정을 대신하는 진단도구가 아닙니다.

## 데이터
- 학습 256,351건, 테스트 90,067건
- 기본 입력 변수 67개
- 학습 데이터의 임신 성공 66,228건(25.8%)

## 분석 및 특성공학
- 시술별 적용 여부에 따라 결측치에 **구조적 의미**가 있을 수 있다고 보고 결측 여부 해석
- 숫자형/범주형 전처리, 타깃 분리, 층화 3-Fold 교차검증
- 배아 이식비율, 배아 저장비율, 미세주입 난자비율, 시술 유형×연령대 등 특성 설계

## 발표자료에 기재된 실험 결과
| LightGBM 실험안 | 3-Fold OOF ROC-AUC |
|---|---:|
| 기본 모델 | 0.739797 |
| 복잡도 완화 | 0.739748 |
| 특성조합+규제 | 0.739787 |
| 특성조합+세분화 | 0.739694 |

발표 시점 최고 OOF AUC는 약 **0.73980**. 기존 프로젝트 소개에 기재된 최종 공개 리더보드 **0.7424306**은 *다른 평가 단계의 별도 수치*이며, 동일한 검증 점수로 취급하지 않습니다.

## 결과 해석 및 한계
- ROC-AUC는 분류 순위를 평가하는 지표이며 실제 임신 성공확률이나 정확도 74%를 뜻하지 않습니다.
- 외부기관 일반화 검증 없음, 동일 환자의 반복 시술 포함 여부 확인 불가
- 예측 확률의 보정(calibration) 검증 필요
- 시술 전후 변수의 실제 활용 시점 검토 필요
- 임신 성공과 생아출산은 다른 결과 지표
