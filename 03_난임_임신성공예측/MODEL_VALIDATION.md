# 난임 임신 성공 예측 | 모델 평가, 버전 차이, 재현성

> 출처: 최종발표 PPTX 44장, 2026.10.15 개발 중간안 PPTX 33장, 초기 노트북. **성과는 팀 공동 결과**로 표시합니다.

## 1. 결과 비교

| 버전 | 구성 | 보고된 성능 |
|---|---|---|
| 중간 발표(10/15) | LightGBM + XGBoost + CatBoost, 92개 전처리 피처 | **OOF 0.7407 / Public LB 0.7422** (발표 반올림) |
| 최종 [A] | F65·S54 트리 모델의 5개 분할 평균 | OOF **0.741126** |
| [A]+[B] | 중간 파생 피처 기반 별도 팀원 모델 결합 | OOF **0.741170** |
| 최종 [A]+[B]+[C] | MLP 추가 블렌딩 | **OOF 0.741226**, **Public LB 0.7424306** |

OOF 점수는 학습 데이터의 교차검증 예측 순위 성능, 공개 LB는 대회 공개 평가점수입니다. **임상 현장의 일반화·환자 상담 정확도·개인 임신 성공확률 보정 수준을 나타내지 않습니다.**

## 2. 최종 발표의 [A] 피처 탐색
- 후보 94개 → Null importance 기반 54개(S54) 선택
- LightGBM F65, LightGBM S54, XGBoost S54, CatBoost S54를 비교·혼합
- 서로 다른 Fold 분할과 모델을 혼합하며 안정성을 검토
- [B]는 다른 전처리의 **92피처**를 이용한 별도 팀원 경로
- [C]는 MLP(64·32 은닉층) 경로

## 3. 중요한 재현성 경계

제공된 `육캔두잇_3-3.ipynb`는 **9개 코드 셀, 9개 마크다운 셀**의 별도 3모델 학습 스크립트입니다.

- 학습 구성은 LightGBM/XGBoost/CatBoost. **최종 [A]+[B]+[C]의 MLP 결합 코드는 포함되지 않음**
- 출력 셀이 없는 상태이며, 원본 `train.csv`, `test.csv`, `sample_submission.csv`는 제공되지 않음
- 코드가 검증 결과를 저장하는 부분이 존재하지만 **이 파일을 실제 실행하여 확인한 점수는 없음**
- 코드에는 **train+test를 합쳐 범주 목록을 만드는 부분**이 있어 최종 발표의 train-only 범주 처리 원칙과 충돌 가능성. 별도 점검 없이 '누수 없는 최종 모델'로 소개하지 않음

## 4. 실제 적용 전 검증 과제

| 주제 | 확인할 점 |
|---|---|
| 환자 기준 분할 | 같은 환자의 여러 시술이 다른 Fold에 섞이는지 |
| 시점 누수 | 시술 전 예측에 시술 후 변수(배아 이식·성공 이후 데이터)를 사용하지 않는지 |
| 정보 누수 | 범주 목록, 결측값 대체, 피처 선택, 블렌딩 계수가 검증 Fold/테스트에 의존하지 않는지 |
| 확률 보정 | 예측값 0.30 그룹에서 실제 성공률도 약 30%인지 |
| 편향 | 난자 기증/본인 난자, 연령대, 시술유형, 기관별 성능이 다른지 |
| 외부 검증 | 새로운 기관·기간에서 ROC-AUC/재현율/보정이 유지되는지 |

## 5. 임상적 해석
관찰 데이터에서 '이식을 하지 않은 주기', '배양 5일 이상', '난자 기증' 등이 성공 여부와 연관되더라도, **해당 치료를 선택하면 임신에 성공한다는 인과 증거는 아닙니다**. 시술의 특정 단계에 도달한 뒤 생성되는 변수로는 사전에 예측할 수 없는 결과도 있으므로 사용 시점을 명확히 정의해야 합니다.
