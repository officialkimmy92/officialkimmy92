**역할**: 도입 기획·의료진 커뮤니케이션·개발사/EMR 협업·현장 적용·품질/사용성 피드백

1. 병동 고위험 환자 조기 인지와 모니터링 개선 필요성을 파악해 병원장에게 도입 제안
