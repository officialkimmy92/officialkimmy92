# 검진센터 대장내시경 약 발송 체크리스트 웹

> 검진 예약 엑셀을 올리면, 장 정리약을 보내야 할 환자를 자동으로 골라 주는 웹 페이지

| 항목 | 내용 |
|---|---|
| 기간 | 2026.08 |
| 형태 | 개인 프로젝트 (실제 현장 업무 개선) |
| 내 역할 | 업무 규칙 정의, 기획, 테스트 |
| 사용 도구 | HTML, JavaScript, Excel |

## 1. 문제

검진센터에서 대장내시경 예약 환자에게 장 정리약(장정결제)을 미리 보내야 합니다.
그런데 예약 엑셀에서 대상자를 **일일이 찾아 손으로 확인**해야 해서 시간이 오래 걸리고 빠뜨릴 위험이 있었습니다.

## 2. 만든 것

- 엑셀 파일을 올리면 대장내시경 예약 환자만 자동으로 골라냅니다.
- 환자마다 **발송 필요 / 발송 완료 / 해당 없음**으로 자동 분류합니다.
- 날짜별로 묶고, 진행률 막대를 보여 줍니다.
- 이름·차트번호로 검색하고, 보낸 환자는 체크해서 표시합니다.
- 매주 새 엑셀을 올려 다시 쓸 수 있습니다.

## 3. 판단 규칙 (현장 규칙을 내가 정의)

위에서부터 순서대로 확인합니다.

1. 이미 보냈으면 → **발송 완료**
2. 대장내시경 날짜·시간이 확정돼 있으면 → **발송 필요**
3. 장정결제 칸에 "x"가 있으면 → **해당 없음**
4. 기준일 이후인데 장정결제 칸이 비어 있으면 → **발송 필요**
5. 장정결제 칸에 값이 있으면 → **발송 필요**

## 4. 배운 점

코드를 짜기 전에 **현장 규칙을 정확한 순서로 정리하는 것**이 가장 중요했습니다.
"날짜가 확정되면 무조건 발송 대상"처럼 현장 사람만 아는 규칙이 결과를 바꿨습니다.
