# 대장내시경 장정결제 발송 체크리스트 — 업무 규칙 명세
> 병원 현장에서 수행한 **예약·발송 업무 규칙 설계**를 공개 가능한 수준으로 정리한 문서입니다. 환자명, 차트번호, 실제 예약 엑셀은 포함하지 않습니다.

## 입력/출력
- **입력:** 예약 엑셀의 대장내시경 여부, 검사 날짜·시간, 장정결제 상태, 발송 이력
- **출력:** 발송 필요 / 발송 완료 / 해당 없음 분류, 날짜별 목록, 검색 및 진행 상태

## 분류 우선순위 (기존 프로젝트 명세 기반)
1. 이미 발송한 건 → **발송 완료**
2. 검사 날짜·시간이 확정된 건 → **발송 필요**
3. 장정결제 항목에 `x` 표시 → **해당 없음**
4. 기준일 이후 예약이면서 장정결제 항목이 비어 있으면 → **발송 필요**
5. 장정결제 항목에 값이 있으면 → **발송 필요**

> 실제 구현에서는 규칙의 순서가 결과에 영향을 줍니다. 특히 검사 확정과 '해당 없음' 표시가 충돌할 경우, 우선순위를 현장 담당자와 재검증해야 합니다.

## 사용자 화면 요구사항
- 발송 상태별 목록, 검색(이름/차트번호), 수동 체크
- 예약 날짜별 묶기 및 업무 진행률 표시
- 매주 새로운 예약 엑셀로 재사용

## 검증용 가상 시나리오
| 가상 입력 | 예상 판정 |
|---|---|
| 이미 발송 처리됨 | 발송 완료 |
| 검사 일시 확정, 미발송 | 발송 필요 |
| 검사 일시 미확정, 장정결제 항목 `x` | 해당 없음 |
| 검사 확정 + `x` 혼재 | 우선순위 확인이 필요한 예외 사례 |

**공개 범위:** 로직과 화면 요구사항만 공개. 실제 환자정보가 담긴 파일은 게시하지 않습니다. 원본 구현 HTML이 확보되면 동작 테스트 후 별도 추가해야 합니다.
