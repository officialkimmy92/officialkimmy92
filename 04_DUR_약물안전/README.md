# 입원환자 약물 안전(DUR) 서비스 기획·분석

> 집에서 가져온 약과 병원에서 새로 받은 약이 겹치지 않게, 위험한 조합을 미리 찾아내는 서비스

| 항목 | 내용 |
|---|---|
| 기간 | 2026.10 ~ 2026.11 (2주) |
| 형태 | 팀 프로젝트 6명 (오즈코딩스쿨 AI 헬스케어, 가상 의료 AI 기업 'OZ헬스' 시나리오) |
| 내 역할 | 의료·약학 도메인 정의, **효능군 중복 판별 기준 수립**, 개인 분석결과 보고서 |
| 사용 도구 | Python(pandas), Excel, PowerPoint |

## 1. 왜 이 문제인가

입원하면 환자가 원래 먹던 약(지참약)과 병원에서 새로 처방한 약이 함께 쓰입니다.
그런데 두 약 목록이 자동으로 비교되지 않아서, **같은 효과의 약이 두 번 들어가거나 함께 쓰면 안 되는 약이 처방되는 일**이 생깁니다.
현장에서 직접 본 문제라서 이 주제를 골랐습니다.

## 2. 데이터

- 교육용 가상 EMR 데이터 (입원 환자 13개 테이블)
- 식약처 DUR 병용금기 자료

## 3. 내가 한 일

1. **"위험한 조합"을 글로 정의**: 병용금기(함께 쓰면 안 되는 약)와 효능군 중복(같은 효과의 약이 겹침)을 나눠서 정의했습니다.
2. **효능군 중복 판별 기준 수립**: 어떤 약끼리 "같은 효능군"으로 볼지 기준을 세워, 데이터에서 셀 수 있게 만들었습니다.
3. **분석결과 보고서 작성**: 지참약 자동 대조가 안 돼서 중복 처방이 생긴다는 점을 핵심으로 정리했습니다.

## 4. 결과

- 입원 환자 **위험 노출률(현 수준 11.3%)**을 핵심 지표(KPI)로 설정
- 과제 정의 → 변수 정의서 → 데이터 분석 → 결과 → 개선안까지 **5단계 분석 보고서** 완성

## 5. 배운 점

현장에서 "당연한" 약물 안전 기준도, 데이터로 쓰려면 하나하나 글로 정의해야 한다는 것을 배웠습니다.
임상 경험이 있어서 이 정의를 빠르고 정확하게 할 수 있었습니다.
