# 보건의료 교대근무자 피로 고위험 분류

> 밤 근무, 휴식 시간, 수면 정보로 피로 위험이 높은 의료인을 미리 찾을 수 있을까?

| 항목 | 내용 |
|---|---|
| 기간 | 2026.09 |
| 형태 | 조별 프로젝트 |
| 목적 | 의료인 피로 관리 → 환자 안전 |
| 내 역할 | 주제 선정, 선행연구 조사, 데이터 추출·정리, 모델 비교 |
| 사용 도구 | Python, pandas, scikit-learn, Google Colab |

## 1. 왜 이 문제인가

피곤한 의료인은 실수할 가능성이 높아지고, 이는 환자 안전과 바로 연결됩니다.
교대근무를 직접 해 본 경험으로 이 주제를 골랐습니다.

## 2. 데이터

- **제7차(2023) 근로환경조사 원시자료** (전체 50,195명)
- 이 중 **보건의료 직종 + 교대근무자** 전체를 직접 추출
- 웹에 정리된 데이터가 아니라, 설명서(코드북)를 보며 국가 조사 원자료를 직접 다뤘습니다.

| 구분 | 변수 |
|---|---|
| 맞힐 것(Target) | 지난 1년 전신 피로 여부 |
| 근무 정보 | 한 달 밤 근무 일수, 일요일 근무 일수, 10시간 넘는 근무 일수, 짧은 휴식(퀵리턴), 순환교대 여부 |
| 수면 정보 | 잠들기 어려움, 자주 깸, 일어날 때 피곤함 |

## 3. 방법

- 로지스틱 회귀, 결정트리, 랜덤포레스트 비교
- 모델 A: 근무 정보만 / 모델 B: 근무 + 수면 정보

## 4. 결과

- 밤 근무, 짧은 휴식(퀵리턴), 일요일 근무가 피로와 관련 있음을 확인했습니다. (선행연구 결과와 비슷)
- 근무 정보만으로는 예측이 어려웠고, **수면 정보를 더하면 예측력이 올라갔습니다.**
- 다만 혼자서 선별 도구로 쓰기엔 아직 부족해서, 한계로 정리했습니다.

## 5. 활용 아이디어

- 수면·피로 셀프체크로 고위험자 조기 발견
- 퀵리턴·밤 근무 등 근무 편성 기준을 고치는 근거로 활용
