# 보건의료 교대근무자 전신 피로 분류

> 제7차(2023) 근로환경조사 원시자료를 활용한 **교육용 탐색적 분석 및 분류 모델**

## 프로젝트 개요
- 자료: 제7차(2023년) 근로환경조사, 전체 응답자 50,195명
- 분석 대상: 보건의료 관련 직종 중 교대근무자 202명
- 예측 목표: 지난 1년간 전신 피로 여부(이진 분류)
- 담당: 주제 선정, 선행연구 검토, 원시자료 추출·재코딩, 모델 비교
- 방법: 로지스틱 회귀, 결정트리, 랜덤포레스트; 근무 정보만 사용한 모델 vs 수면 정보 추가 모델 비교

## 핵심 결과
- 근무 관련 변수만 이용한 피로 분류에는 한계
- 수면 관련 변수를 추가한 경우 분류 성능 개선 방향을 관찰
- 표본수와 조사 구조의 제약으로 **임상 선별 도구로 사용할 수준이라고 주장하지 않음**

## 공개 파일
- [KWCS7_shift_fatigue_analysis.ipynb](./KWCS7_shift_fatigue_analysis.ipynb): 실제 분석 노트북의 코드·마크다운을 보존한 **출력 제거 공개본**
- 원시자료 CSV 및 개별 설문 응답 데이터는 포함하지 않음
- 실행을 위해서는 별도 접근한 제7차 근로환경조사 원시자료를 노트북 안내에 따라 직접 준비해야 함

## 주의
노트북의 셀 출력 및 실행 기록은 공개 시 개인정보/원자료 노출을 피하기 위해 제거했습니다. 결과 수치 재현은 원자료와 실행환경에 따라 재확인해야 합니다.
