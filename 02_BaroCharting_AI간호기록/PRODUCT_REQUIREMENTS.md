# BaroCharting — 제품 요구사항 및 공개 범위
> 개인 프로젝트의 기획 관점을 정리했습니다. 실제 환자정보나 비공개 서비스 코드는 포함하지 않습니다.

**서비스 데모:** https://barocharting-ai.ai.studio/

## 해결하려는 문제
간호기록 작성 시 반복 입력이 발생하고 기록자의 숙련도에 따라 문장과 서식에 편차가 생길 수 있습니다. 임상에서 사용되는 용어와 문서 구조를 입력·출력 설계에 반영하는 간호기록 초안 작성 도구를 기획했습니다.

## 사용자
- 병동·외래·진료지원 환경에서 간호기록 초안을 작성하는 간호사
- 결과를 검토·수정하고 최종 기록 책임을 지는 의료인

## 핵심 기능 요구사항
| 요구사항 | 설계 목적 |
|---|---|
| 핵심 상태·관찰·처치 내용을 입력 | 자유서술 부담 완화 |
| 임상 문서 맥락에 맞춘 초안 생성 | 의료진의 빠른 검토 지원 |
| 생성 초안 수정 | 자동 출력물을 확정 기록과 구분 |
| 의학 용어·약어 사용 고려 | 실제 현장 표현과의 괴리 축소 |

## 반드시 지켜야 할 안전 조건
- 출력 결과는 **초안**이며 의무기록으로 자동 확정하지 않음
- 입력되지 않은 검사·처치·관찰 사실을 AI가 임의로 만들어 내지 않도록 검토 필요
- 개인식별정보·실제 환자정보를 공개 저장소 및 데모에 포함하지 않음
- 의료인 확인을 통한 오류 수정과 책임 소재 분리

## 검증 현황
- 현재 GitHub 저장소에는 개인 프로젝트의 서비스 소개와 데모 링크를 공개
- 의료기관 도입, 정식 임상 검증, 기록 시간 단축 효과 및 정확도 향상 수치는 **확인된 근거가 없어 기재하지 않음**
- 추후 공개 가능한 소스코드·화면 캡처·테스트 케이스가 확보되면 별도 추가 예정
