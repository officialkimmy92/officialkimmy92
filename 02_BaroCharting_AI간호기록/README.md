# 바로차팅(BaroCharting) | 생성형 AI 간호기록 자동화 웹사이트

> 간호사가 핵심 정보만 넣으면, AI가 간호기록 초안을 만들어 주는 웹사이트

🔗 **서비스 바로가기**: https://barocharting-ai.ai.studio/

| 항목 | 내용 |
|---|---|
| 형태 | 개인 프로젝트 |
| 내 역할 | 기획 · 개발 · PM |
| 사용 기술 | 생성형 AI, 웹 |

## 1. 왜 만들었나

간호기록은 매 근무마다 써야 하는데 시간이 많이 들고, 사람마다 쓰는 방식이 다릅니다.
병동·중환자실·정신과·PA에서 기록을 직접 써 본 경험으로, **기록 시간을 줄이고 형식을 맞추는 도구**가 필요하다고 느꼈습니다.

## 2. 설계할 때 신경 쓴 것

- **실제 간호기록 구조 반영**: 현장에서 쓰는 기록 순서와 형식을 그대로 따랐습니다.
- **임상 용어**: 간호사가 실제로 쓰는 용어와 약어를 반영했습니다.
- **입력 → 출력 흐름**: 바쁜 현장에서 짧게 입력해도 쓸 만한 결과가 나오도록 화면 흐름을 설계했습니다.
